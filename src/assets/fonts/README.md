Static font instances used by server-rendered images (share cards, Open Graph
images, social templates). Both families are licensed under the SIL Open Font
License 1.1 (see the OFL-*.txt files), which permits bundling and use in
images and video. The website itself loads the variable versions via
next/font/google.

- Archivo-ExpandedExtraBold.ttf — Archivo, width 125, weight 800
- Archivo-SemiBold.ttf          — Archivo, width 100, weight 600
- Inter-Medium.ttf / Inter-Bold.ttf — Inter, weights 500 / 700
